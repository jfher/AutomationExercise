# Contact Test Plan

## Objetive

Validate that users can send message to contact support and attach files if needed.

---

## Scope

Included

- Contact page
- Contact form
- File upload
- Confirmation dialog
- Success message

Excluded

- Backend email delivery
- Spam filtering

---

## Test Types

- Smoke
- Regression
- Positive
- Negative
  
---

## Entry Criteria

Application available.

## Exit Criteria

Smoke Passed.

Regression Passed.

No Critical Defects.
